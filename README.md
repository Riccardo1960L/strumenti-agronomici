# Strumenti agronomici

Calcolatori agronomici che girano nel browser, senza installazione: radiazione solare e accrescimento (`ric-sole`), reti ombreggianti (`ric-sun`) e confronto di coperture per serra (`ric-serra-materiali`).

Aprire `index.html` per la presentazione, oppure usare il sito pubblicato con GitHub Pages.

**Avvertenza.** Strumenti sperimentali: modelli semplificati e parametri indicativi, non sostitutivi della valutazione di un tecnico.

**Dati.** Meteo: Open-Meteo.com (CC BY 4.0). Luoghi: Nominatim, © contributori di OpenStreetMap.
