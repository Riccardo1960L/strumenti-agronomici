# Strumenti agronomici

Calcolatori agronomici che girano nel browser, senza installazione:

- **Radiazione solare e serre**: radiazione solare e accrescimento (`ric-sole`), reti ombreggianti (`ric-sun`), confronto di coperture per serra (`ric-serra-materiali`).
- **Irrigazione**: piano di irrigazione, irrigazione con tensiometri, microirrigazione, bilancio idrico del suolo.
- **Clima e viticoltura**: gradi-giorno (`ric-gdd`) e una sezione dedicata alla vite (cartella `viticoltura/`) con indice di Huglin, indice di siccità di Riou e valutazione del terroir.

Aprire `index.html` per la presentazione, oppure usare il sito pubblicato con GitHub Pages.

**Avvertenza.** Strumenti sperimentali: modelli semplificati e parametri indicativi, non sostitutivi della valutazione di un tecnico.
